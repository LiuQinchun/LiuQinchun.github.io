DNS 抓包总结

这已经不是“看到了 DNS 包”这么简单了。

你现在实际上已经在真实抓包里看到了：

  • ✅ DNS Request
  • ✅ DNS Response
  • ✅ UDP/DNS 通信
  • ✅ Source / Destination IP
  • ✅ A 记录
  • ✅ AAAA 记录
  • ✅ CNAME
  • ✅ Transaction ID
  • ✅ Request 与 Response 的对应关系
